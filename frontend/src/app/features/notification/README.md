# features / notification

Modelo y cliente HTTP para las notificaciones (confirmaciones y
recordatorios de entrevista). No tiene una pantalla propia en este
cascaron: en el sistema real, la mayoría de las notificaciones son correos
que el usuario recibe fuera de la aplicación; este módulo queda listo por
si se necesita, por ejemplo, un panel de "notificaciones pendientes" para
el reclutador.
